# japyjapy

An app designed to help foreigners learn business Japanese more effectively and improve their Japanese communication skills.

The core idea: fluent speakers often still struggle with *impromptu* workplace speech — rambling, imprecise, lacking structure. japyjapy drills that specific weakness through a **scenario → speak → feedback** loop, and turns the feedback into a personal vocabulary book.

## Features

### 🎙 Speaking practice (スピーキング練習)

1. Pick an industry, scenario type (進捗報告 / 顧客対応 / 部門連携 / トラブル報告) and difficulty (90 / 120 / 150s).
2. Get a realistic scenario card — context, your task, source material to work from, a countdown timer, and a tip.
3. Speak into the mic (browser speech recognition, `ja-JP`) or type directly into the transcript box.
4. Submit and receive structured feedback:
   - **文字起こし** — what you actually said
   - **時間フィードバック** — over/under the limit
   - **模範解答** — a polished rewrite of *your own* content
   - **構成へのフィードバック** — up to 3 structural issues, each with the offending quote and a fix, plus what you did well
   - **語彙へのフィードバック** — up to 5 wording upgrades, each one addable to your word book in a click

### 📚 Word book (単語帳)

Full CRUD over your saved vocabulary — add manually or straight from practice feedback, inline edit, mark as learned, delete. Duplicate words are detected and blocked with a warning.

### 🏠 Home

Learning stats, a 14-day line chart of cumulative vocabulary growth, and a study goal with progress bar.

### 👤 Profile

Username, bio, and account deletion.

## Tech stack

- **Vanilla JavaScript, no build step** — plain `index.html` + `app.js` + `style.css`
- **Supabase** for auth (email/password, Google & GitHub OAuth) and Postgres storage, via a small hand-rolled REST client
- **Web Speech API** for speech-to-text
- **Inline SVG** for charting — no chart library
- Light/dark theme via CSS custom properties

## Running locally

No install or build required — serve the directory statically:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

Speech recognition requires a Chromium-based browser (Chrome/Edge). In other browsers the mic button is replaced with a note and you can type your response instead — the rest of the flow works identically.

## Supabase setup

Point `SUPABASE_URL` / `SUPABASE_ANON_KEY` at the top of `app.js` to your own project, then create two tables:

- `user_profiles` — keyed by `user_id`, plus `username`, `bio`, `study_goal`
- `vocabularies` — `id`, `user_id`, `word`, `reading`, `meaning`, `example`, `scenario`, `learned`, `created_at`

Both need RLS policies scoping rows to `auth.uid()`, **and** table-level grants for the `authenticated` role:

```sql
GRANT SELECT, INSERT, UPDATE, DELETE ON public.vocabularies  TO authenticated;
GRANT SELECT, INSERT, UPDATE, DELETE ON public.user_profiles TO authenticated;
```

RLS policies alone are not enough — without the grants every request fails with `42501 permission denied`.

A unique constraint on `(user_id, word)` is recommended so duplicate vocabulary is rejected at the database level as well as in the UI.

## AI integration status

Practice scenarios and feedback are currently generated by **local mock logic**, not a language model — a small scenario pool plus heuristics for filler-word detection and structure checks. No API key is needed and nothing is sent anywhere.

The two-stage contract (`generate_scenario` → `analyze_response`), including the full system prompt and JSON schemas, is documented in [`docs/system-prompt.md`](docs/system-prompt.md). To go live, replace `mockGenerateScenario` / `mockAnalyzeResponse` in `app.js` with real LLM calls — ideally from a Supabase Edge Function so the API key stays server-side.

## Known limitations

- Feedback quality is bounded by the mock heuristics until a real model is wired up.
- The home chart tracks vocabulary added per day. Review frequency and mastery trends would need a `learned_at` timestamp or a review-log table, which the current schema doesn't have.
- The UI is in Japanese throughout; there is no language switcher yet.
